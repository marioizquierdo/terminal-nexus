## The way out of the Build Phase

### F47 — Start is a regular menu row, at the bottom: `[s] Start Pulse`

> The Start button is too large. It just needs to be the last option on the menu. Let's keep it as a
> regular menu item, at the bottom, called "[s] Start Pulse".

**Built.** The boxed button is gone. `[s] Start Pulse` is the menu's last row, on the panel's bottom
line, drawn and highlighted like every other row: Up/Down reach it, Enter or Space press it, a click
presses it, `s` still presses it from anywhere. It is dim while a Nexus power is waiting to be picked
(pressing it is then refused with the reason, as before), and it reads *active* while its question is
open, like `[n] Nexus` behind its popup. It belongs to the menu, so Explore Map, which replaces the menu
with what is under the cursor, hides it as it hides the others. The line under the menu says what it does
while it is highlighted.

### F48 — A menu can always be walked with Up, Down and Enter

> It is important that the menu can always be navigated with up/down/enter. The hotkeys and mouse
> clicks are the additional enhanced functionality. Remember this on the ui design spec please

**Built.** It is now a rule in [`../ui-patterns.md`](../../system-design/ui-patterns.md) (a goal in section 0, and the first
pattern of the menu section): every action a menu offers is a row, and every row can be reached with
Up/Down and pressed with Enter, with nothing else; hotkeys and clicks are shortcuts to the same rows,
never the only way. The boxed button broke it — `s` and a click reached it, Up and Down did not — which
is why it went.

## The start confirmation

### F49 — A confirmation screen titled "Battle Round 1", not a question

> Popup should not be a question, but a confirmation screen. The title should just say "Battle Round 1".
> The text body should announce the pulse. We will have chances to customize this text: campaign
> missions may inject pulse-n text here. I feel we may keep the term "pulse" to ourselves and instead
> call this "battle round". The default should be "Activate Nexus. Collect Resources. Spawn Units."

**Built, with one thing to settle.** The popup's title is `Battle Round 1` (the number counts up when
the loop back into the next Build Phase exists, gate 6B). Its body is one announcement, by default
"Activate Nexus. Collect Resources. Spawn Units.", and a mission can supply its own text for round *n*
(the Build Phase's context has an optional table of them; nothing supplies one yet). **To settle:** he
wrote the menu row as "[s] Start Pulse" and also felt the word "pulse" could stay private. As built, the
row and the running screen's title still say Pulse and only this popup says Battle Round. Registered as
Q68 with a recommendation — one player-facing name — to be settled with the menu reorganisation (F51),
because the menu row is one of the places the word lives.

### F50 — Only `[s] Start`; Esc cancels

> Remove the "Keep building" option, only "[s] Start" is needed (esc will cancel as usual).

**Built.** The popup has one row, `[s] Start`, highlighted; Enter, Space and `s` press it. `n` is no
longer a key there; Esc, `x`, the top bar's `close [esc]` and a click outside all go back. The command
that answered the old question no longer says yes or no: it starts the Pulse, and going back is the
cancel every popup already has.
